# assets

Recursos estáticos genéricos (imágenes, íconos) no ligados a una sola sección. Un asset propio de una sola feature vive dentro de esa carpeta en `features/`.

`logo/` guarda los recursos oficiales de la UNSL tomados de `unsl.edu.ar`: `favicon.ico`, `logo-unsl-192.png` (ícono para pestañas y dispositivos), `logo-unsl-blanco.png` (barra) y `logo-unsl-color.png` (pie).
