# auth

El ingreso al sitio (`login`). Por ahora es sólo una maqueta: no hay backend de autenticación real todavía, así que no valida credenciales, no guarda sesión y no protege ninguna ruta. Al ingresar lleva al panel de `features/panel`. Se llega desde el botón "Ingresar" del pie de página; la barra de navegación no lo enlaza.
