# auth/login

Página de ingreso (`/login`), se llega desde el botón "Ingresar" del pie. Es una maqueta: al enviar el formulario no valida nada ni guarda sesión, y lleva a `/login/estadisticas` (con `replace`, para que "Atrás" no vuelva al formulario). Los tres campos son controlados y llevan `autoComplete`.
