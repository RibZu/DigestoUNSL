# ayuda

Página de preguntas frecuentes (`Ayuda.jsx`): dudas generales, una tanda de preguntas por cada
pestaña del sitio y enlaces de interés, con un índice de anclas que se genera de los datos.

El contenido vive en `ayuda.contenido.js` (`BLOQUES_AYUDA` y `ENLACES_DE_INTERES`) y el componente
solo lo presenta. Si una pestaña cambia, se revisan sus preguntas: las respuestas tienen que nombrar
los campos, botones y etiquetas tal como se ven en pantalla.

Se accede desde el pie de página; no forma parte de la barra de navegación principal.
