# estadisticas

Estadísticas públicas del Digesto: cantidad de documentos, con dos vistas — enviados por dependencia/oficina, o por tipo de documento (equivalente a `estadisticas.php3`).

No confundir con el dashboard propio de `features/auth/panel` (búsquedas sin resultado y términos más buscados) — son datos distintos, de fuentes distintas.
