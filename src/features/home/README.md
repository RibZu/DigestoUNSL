# home

Página de inicio (`Home.jsx`). Es la única sección con diseño propio de la feature de rediseño
visual institucional; el resto de las secciones usa `SectionPlaceholder`. Muestra tres bloques de
vidriera con contenido de ejemplo hardcodeado — búsqueda, novedades y concursos — cada uno con un
link a su sección completa (`HomeShowcaseCard`, en esta misma carpeta: es un componente propio del
home, no genérico). No hay integración real con datos todavía.
